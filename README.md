# TaskFlow

TaskFlow is a simple and user-friendly Task Management Website designed to help users organize and manage their tasks efficiently.

## Features

- Add new tasks
- View all tasks
- Mark tasks as completed
- Delete tasks
- Track total and completed tasks
- Simple and responsive user interface

## Technologies Used

- HTML
- CSS
- JavaScript
